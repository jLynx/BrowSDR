# P25 reception

Select **DSD**, set a **12,500 Hz** VFO bandwidth and tune to the channel's
receive/output frequency. P25 is detected automatically; there is no separate
P25 mode switch. Initially leave squelch disabled so it does not cut off short
digital bursts. All VFOs being monitored must fit within the SDR sample span.

The implemented decoder handles **P25 Phase 1 C4FM** at 4,800 symbols/s with
IMBE voice. It validates the BCH-protected Network Identifier (NID), removes
status symbols, reads all nine voice frames in each LDU, and decodes protected
HDU, LDU1, LDU2 and TDULC metadata. Both signal polarities are supported.

A confirmed channel displays **P25P1**, its **NAC** (Network Access Code) and
**DUID** (data unit type). Talkgroup/source IDs appear when decoded from valid
link control. HDU/LDU2 can supply the encryption algorithm and key identifier.
Encrypted calls display **ENCRYPTED · NO AUDIO** and are muted. Control/data
units can be identified by their NID but their messages are not yet parsed;
a control channel does not contain speech.

Current limits: no P25 Phase 2 TDMA, CQPSK/LSM demodulation, automatic trunk
following or decryption. On a trunked system, tune individual voice channels
and expect calls to move between them.

## Finding and tuning a P25 channel

P25 has no single worldwide frequency. Consult current frequency directories,
repeater listings or spectrum-licensing records for your area, and look for
**P25 Phase 1 C4FM** channels. A published assignment may be outdated, quiet
or shared with analogue FM. An RF peak alone does not confirm the protocol;
look for a validated P25 lock and NAC in the decoder panel.

For a conventional repeater, tune its output frequency. On a trunked system,
use a voice channel for speech testing; a control channel carries signalling.
Choose a known unencrypted channel or use the public recording described below
to verify voice decoding.

To monitor several channels, create one DSD VFO per frequency and select a
center frequency and sample rate that keep every VFO's full bandwidth within
the captured span. Keep the desired channels away from the center-frequency
DC spike. Select the receiver and antenna input that match the physical
connector in use; for example, LimeSDR RX1 L uses **RX1 / LNAL**.

## Decoder verification

The independent [P25 fixtures](../test/fixtures/README.md) check BCH correction,
status-symbol positions, frame boundaries, FEC, metadata, polarity, ring-buffer
wrap, encrypted muting and transitions back to clear voice. Run:

```sh
npx vitest run --pool forks --exclude test/index.spec.js
npx vitest run test/index.spec.js
node scripts/validate-dsd.mjs --p25-self-test
node scripts/validate-dsd.mjs --p25-self-test 0 invert
node scripts/validate-dsd.mjs --self-test
npm run typecheck
npm run build
```

The RF-to-codec P25 self-test sends independently encoded synthetic silence
through the actual Rust/WASM IQ filter, FM discriminator, timing recovery,
framing and mbelib IMBE decoder. It must produce 180 frames / 28,800 samples
at 8 kHz with the expected NAC and talkgroup and zero reported codec errors.
This verifies framing and codec integration, **not live intelligible speech**.

The decoder was also tested with SigIDWiki's public
[Motorola XTS5000 C4FM I/Q recording](https://www.sigidwiki.com/wiki/File:P25-C4FM-VC_IF.wav)
(PCM24 stereo, 24 kHz, 8.32 seconds). It acquired 29 P25 units, decoded 252
IMBE frames / 40,320 audio samples, and recovered NAC 0x293, talkgroup 1,
source 1 and clear ALGID 0x80. Of the 252 voice frames, 246 reported zero
codec errors. This is a real recording check; live reception with the attached
SDR has not yet been confirmed. The external recording is not bundled in this repo.
To inspect decoded audio from your own PCM16/24 or float32 stereo I/Q WAV:

```sh
node scripts/validate-dsd.mjs path/to/iq.wav 0 --audio-out=decoded.wav
```

All P25 DSP runs in the browser's Web Workers. Normal builds use the existing
committed mbelib JavaScript/WASM assets; this change adds no codec download,
Emscripten install step or Cloudflare binding.
