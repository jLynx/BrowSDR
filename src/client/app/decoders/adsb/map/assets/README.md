# Aircraft silhouettes

Extracted SVG shapes and type/category mappings from [tar1090 markers.js](https://github.com/wiedehopf/tar1090/blob/e784ee5ae82948f41efe3ef5c235ade0943ab8ff/html/markers.js), revision `e784ee5ae82948f41efe3ef5c235ade0943ab8ff`.

Developed by Matthias Wirth, based on FlightAware dump1090. A320/B737 family refinements contributed by pimlie. Licensed GPL-2.0-or-later; see [LICENSE](LICENSE). The JSON preserves the upstream paths and mappings; BrowSDR renders them with Leaflet. No upstream application logic is executed.
